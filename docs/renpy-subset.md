# Ren'Py 有限语法导入合同

BranchCheck 1.2 可以只读导入一个显式指定的 UTF-8 `.rpy` 文件，从 `label start` 开始检查新游戏默认状态。它不是 Ren'Py 项目加载器，不扫描其他文件，也不执行脚本、Ren'Py SDK、Python 回调或引擎 API。

导入器先验证整份文件，再生成 `schema_version=1` 的布尔状态模型。不可达 label 中的未知语句也会使整次导入失败；不支持的内容不会被静默删除后继续分析。

## 支持范围

| 构造 | V1.2 合同 |
|---|---|
| 空行与注释 | 空行、整行注释，以及字符串外的行尾注释 |
| 初始化 | 顶层 `default flag = True` / `False`；每个变量只声明一次 |
| label | 顶层 ASCII 全局 ID；不带点号、参数或局部作用域 |
| 赋值 | `$ flag = True` / `False`；只能写已声明布尔变量 |
| 条件 | 嵌套 `if` / `elif` / `else` |
| 菜单 | 无名、无参数 `menu:`；单行字符串选项，可附 `if expr` |
| 控制流 | 静态 `jump label_name`、无参数 `return`、`pass` |
| 叙述 | 无说话者前缀的单行普通引号字符串；按不改变布尔状态处理 |

条件表达式只接受布尔字面量、已声明变量、`not`、`and`、`or`，以及 `变量 ==/!= True/False` 的单次比较。括号可以改变组合顺序。表达式由 Python 标准库 AST 解析后逐节点白名单转换；不会调用 `eval` 或 `exec`。

示例：

```renpy
default has_photo = False

label start:
    menu:
        "调查实验室":
            $ has_photo = True
        "暂时离开" if not has_photo:
            jump leave
    if has_photo:
        jump truth
    else:
        jump leave

label truth:
    "你确认了照片中的线索。"
    return

label leave:
    return
```

## 控制流语义

- `default` 只贡献新游戏初始值，不在它的文本位置产生运行步骤。
- label 的块正常结束后贯穿到文件中的下一个 label；label 不是函数，也不会自动成为结局。
- `if` / `elif` 按源码顺序只执行第一条满足的分支。无 `else` 且全部条件为假时继续执行条件块之后的语句。
- menu 的每个可用选项都是玩家可能的选择。只要有一个选项可用，就不存在跳过 menu 的路线；全部不可用时才自动继续到 menu 后继。
- 布尔赋值在离开赋值步骤时生效，下一条条件读取更新后的值。兄弟分支的状态彼此独立。
- `jump` 只连接目标 label；`return` 结束当前片段。二者都不会继续执行原位置的下一条语句。
- 最后一个 label 的最后一条顶层语句必须字面上是静态 `jump` 或无参数 `return`。导入器不会把文件末尾猜成成功结局。

编译会增加自动执行边，因此报告中的最短路径是核心图中的最少转移数，不等同于最少玩家操作数。menu 选项会标为玩家选择；label 进入、顺序执行、条件分派、赋值、jump 与 menu 全禁回退会标为自动执行。完整路径仍保留这些步骤和赋值证据。

## 字符串、注释与缩进

- 接受 LF、CRLF 和可选 UTF-8 BOM。
- 每级缩进必须恰好增加四个空格；拒绝 Tab、混合缩进、跳级、空块、孤立 `elif` / `else` 和续行。
- 扫描注释及结构冒号时会识别引号和反斜线转义；字符串中的 `#` 与 `:` 不是语法。
- 字符串只接受普通单/双引号和受支持的基本转义。拒绝前缀字符串、三引号、跨行、隐式拼接及相邻字符串。
- 字符串解码后如包含 `[` 插值或 `{` 文本标签入口，会明确拒绝。本阶段不验证 Ren'Py 展示系统。

## 明确拒绝

V1.2 不支持 `define`、`init`、`python:`、任意函数调用、`$ x = not x`、`call`、动态 jump、带值 return、`while`、数值/字符串状态、screen、image、transform、ATL、scene/show/hide/with、音频指令、带说话者 say、菜单提示、命名菜单、menu set/with/arguments、局部 label、参数 label、多文件状态、存档、回滚或初始化钩子。

这些语法可能是合法 Ren'Py；被拒绝只表示 BranchCheck 1.2 没有建模。错误会给出相对文件名和实际源行，不会声称已检查被跳过的行为。

## 资源限制

导入器对源文件字节数、物理行数、单行长度、语句数、块嵌套、表达式长度/深度/AST 节点数和编译节点数设置固定上限。超过任一上限会作为带位置的 `INVALID_INPUT` 返回，而不是暴露 `RecursionError` 或继续无界展开。

这些限制用于保证恶意或意外输入不会让解析、条件转换或控制流编译失控；它们与分析阶段的 `--max-states` / `--max-transitions` 不同。后两项限制编译模型的状态搜索，达到时退出码为 3，未访问内容保持未知。

当前具体上限：源文件 1 MiB、10000 物理行、每行 4096 字符、5000 个 AST 语句（含分支标题）、16 层块嵌套；单表达式 2048 字符、256 个 Python AST 节点、24 层条件。编译生成的守卫累计最多 100000 项；节点数受语句数约束，不超过 5000。这些保守限制为组合守卫保留了现有 loader 的 32 层条件深度余量，并限制长 elif 链产生的平方级体积。基本字符串转义仅支持 `\\`、`\"`、`\'`、`\n`、`\r`、`\t`。

## 不能保证的结论

“完整通过”只覆盖这个单文件、布尔状态、静态控制流和新游戏默认值模型。纯叙述按无状态步骤抽象；工具不模拟其他 `.rpy` 文件、引擎外部逻辑、Python、显示层、存档或回滚，也不会从对白推断作者约束。没有断言时，“到达了不符合作者意图但能 return 的 label”未必能由模型证明为错误。

本仓库在 V1.2 开发前没有可直接导入的真实 `.rpy` 原文。`examples/renpy/` 是为合同验证编写的 adapted 示例，不代表真实 Ren'Py 工程已经接入。
